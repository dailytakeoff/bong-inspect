# Bong Inspect

Client-side Fabric mod for Minecraft 26.3. Press a key and your character brings a glass bong
to their face, takes a hit (the chamber fills with smoke and bubbles), blows out campfire smoke,
then inspects the piece CS:GO-style before putting it away. No item is added; it's purely an animation,
so it works on any server.

## Keys (change them in Options > Controls > Key Binds > "Bong Inspect")
- **G** – take a hit, blow out smoke, then inspect
- **H** – inspect only

## Install
Drop `BongInspect-<version>.jar` into your `mods` folder with Fabric Loader and Fabric API for 26.3.

Other players don't see the animation or the smoke (client-side only).
